# Igreja Betesda

Site institucional multipágina desenvolvido com HTML, CSS, JavaScript e Bootstrap.

## Estrutura

- `index.html`: página inicial.
- `pages/`: páginas institucionais e de conteúdo.
- `pages/ministerios/`: páginas individuais dos ministérios.
- `assets/images/`: imagens do site, incluindo a identidade visual.
- `css/style.css`: estilos do projeto.
- `js/main.js`: scripts compartilhados do site.

## Execução local

Na raiz do projeto, inicie um servidor HTTP estático:

```bash
python -m http.server 8000
```

Depois, acesse `http://localhost:8000/`.
